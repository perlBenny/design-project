# 4. Repo tour

## Folders

| Path             | What lives there                                         | Status  |
| ---------------- | -------------------------------------------------------- | ------- |
| `db/migrations/` | SQL migrations — the only source of the schema           | Done    |
| `db/seed/`       | `base.sql` (roles, permissions), `dev.sql` (sample data) | Done    |
| `db/tests/`      | `constraints.sql` — tests that the DB rejects bad data   | Done    |
| `db/schema.sql`  | Generated by dbmate. Commit it, never edit it            | Done    |
| `docs/`          | This book and `SPEC.md`                                  | Done    |
| `.github/`       | CI workflows, AI instructions and skills                 | Done    |
| `frontend/`      | The website and admin panel                              | Planned |
| `backends/node/` | Main backend                                             | Planned |
| `api-spec/`      | `openapi.yaml`                                           | Planned |
| `tests/e2e/`     | API tests that run against any backend                   | Planned |
| `infra/caddy/`   | Reverse proxy for local prod                             | Planned |

## Root config files

| File                  | Why it exists                                                      |
| --------------------- | ------------------------------------------------------------------ |
| `package.json`        | Root scripts (`dev`, `check`, `db:*`) and the pinned pnpm version  |
| `pnpm-workspace.yaml` | Lists the packages of the monorepo                                 |
| `tsconfig.base.json`  | Shared strict TypeScript settings; packages extend it              |
| `.oxlintrc.json`      | Lint rules ([oxlint](https://oxc.rs) — very fast, written in Rust) |
| `.prettierrc.json`    | Formatting ([Prettier](https://prettier.io))                       |
| `.editorconfig`       | Same indentation and line endings in every editor                  |
| `.gitattributes`      | Forces LF line endings, even on Windows                            |
| `.nvmrc`              | Node version for local and CI                                      |
| `compose.yml`         | Docker services. See [Infra](06-infra.md)                          |
| `.env.example`        | Every setting with safe dev values. Copy to `.env.dev`             |
